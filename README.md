# Sajee's Kitchen Catering & Events website

A responsive, single-page catering business website made with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile menu and WhatsApp enquiry form

## Run locally
Open `index.html` in a browser. For a local server, run:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.

## Before publishing
- Confirm the phone number and WhatsApp number with the business owner.
- Confirm services, operating hours, menus and pricing before publishing claims.
- Replace stock photos with real photos of Sajee's Kitchen's food and events.
- The enquiry form opens WhatsApp; it does not save form data to a server.
